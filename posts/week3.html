Which Marvel characters are more — or less — central than an equivalent random network would expect? Rank the observations, then open a character to see their complete centrality profile.

Surprise is a relationship.

A centrality value only becomes interesting when it has a reference point. Here, the reference is 80 Erdős–Rényi graphs with the same number of nodes and edges as the undirected Marvel projection. We compare each real character–measure observation with that null distribution.

Z-score = (real centrality − null mean) / null SD

Positive z-scores mean higher centrality than expected under the null model. Negative z-scores mean lower centrality. The larger the absolute z-score, the more unusual the observation is relative to the null model.

When a node disappears.

Betweenness measures how often a character sits on shortest paths. Node removal asks a different question: does the network actually lose its largest connected backbone when that character disappears?

Each point uses observed betweenness from the original Marvel network. The y-axis is the giant component reduction after removing one character: 1 − (giant component after removal / original network size).

Direction.

Some characters link outward to many others while receiving few links themselves. Others are frequently referenced but link outward relatively little. This section compares those two directional roles without replacing the actual link counts with percentiles.

Direction difference = out-rank percentile − in-rank percentile. Positive values indicate an outgoing-over-incoming asymmetry; negative values indicate an incoming-over-outgoing asymmetry.
